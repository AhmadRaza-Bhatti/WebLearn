WebLearn is a simple educational website created to provide organized lectures and learning resources for Web Development.

What is WebLearn?

WebLearn is a learning platform designed for students studying Web Development. It brings lectures and important concepts together in one simple and easy-to-use website.

The main goal of WebLearn is to make learning web development easier by presenting course material in an organized and accessible way.

What You'll Learn

HTML

Learn the basic structure and elements of web pages.

CSS

Learn how to style and create attractive web page layouts.

JavaScript

Understand the basics of adding interaction to websites.

Technologies Used

HTML5 CSS3 Bootstrap
