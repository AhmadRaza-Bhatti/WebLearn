LECTURE 03

HTML Tables

Learn how to organize and display information in rows and columns using HTML tables.

Lecture Video

Watch & Learn

About This Lecture

HTML tables are used to display structured information in rows and columns. They are useful for presenting student records, marksheets, schedules, product information and other data that needs to be compared.

In this lecture, we will learn the basic table elements, table sections, merged cells, CSS styling, accessibility and responsive table layouts.

What You'll Learn

Table Structure

Understand rows, headings, cells and captions.

Merging Cells

Combine cells using colspan and rowspan.

CSS and Responsive

Style tables and make them easier to use.

1. Basic Table Structure

The table element creates a table. The tr element creates a row, th creates a heading cell, and td creates a normal data cell.

  • table: Defines the complete table.
  • tr: Defines a table row.
  • th: Defines a heading cell.
  • td: Defines a data cell.

Example

<table>
     <tr>
          <th>Name</th>
          <th>Subject</th>
          <th>Marks</th>
     </tr>

     <tr>
          <td>Ahmad</td>
          <td>Web Development</td>
          <td>85</td>
     </tr>

     <tr>
          <td>Ali</td>
          <td>Programming</td>
          <td>90</td>
     </tr>
</table>

The first row contains the column headings. The next two rows contain the actual data. Each row should have the appropriate number of cells for its columns.

2. Table Sections

HTML provides elements that divide a table into meaningful sections. These sections make larger tables easier to organize and maintain.

  • caption: Gives the table a title or description.
  • thead: Groups the heading rows.
  • tbody: Groups the main data rows.
  • tfoot: Groups summary or footer rows.

Example

<table>
     <caption>Student Marks</caption>

     <thead>
          <tr>
               <th>Name</th>
               <th>Marks</th>
          </tr>
     </thead>

     <tbody>
          <tr>
               <td>Ahmad</td>
               <td>85</td>
          </tr>

          <tr>
               <td>Ali</td>
               <td>90</td>
          </tr>
     </tbody>

     <tfoot>
          <tr>
               <th>Total Students</th>
               <td>2</td>
          </tr>
     </tfoot>
</table>

These elements describe the purpose of each table section. They do not automatically provide a complete visual design; CSS can be used to style them.

3. Merging Table Cells

Sometimes a table needs a cell that covers more than one column or row. HTML provides two attributes for this purpose.

Colspan

The colspan attribute makes one cell extend across multiple columns. 

<table>
     <tr>
          <th colspan="2">Student Information</th>
     </tr>

     <tr>
          <td>Name</td>
          <td>Ahmad</td>
     </tr>
</table>

Rowspan

The rowspan attribute makes one cell extend across multiple rows. 

<table>
     <tr>
          <th rowspan="2">Web Development</th>
          <td>HTML</td>
     </tr>

     <tr>
          <td>CSS</td>
     </tr>
</table>

Remember: colspan merges cells horizontally, while rowspan merges cells vertically. When using either attribute, adjust the remaining cells so the table structure stays correct.

4. Styling Tables with CSS

CSS improves the appearance and readability of tables. Borders separate cells, padding creates space inside cells, and text-align controls horizontal alignment.

Border and Border Collapse

table {
     width: 100%;
     border-collapse: collapse;
}

th, td {
     border: 1px solid #dcebe3;
     padding: 12px;
     text-align: left;
}

The border property adds lines around the cells. The border-collapse property combines neighboring cell borders into a single border.

Striped Rows

The nth-child selector can apply different styles to alternating rows. This makes larger tables easier to read. 

tbody tr:nth-child(even) {
     background-color: #e8f5ee;
}

Hover Effect

The hover pseudo-class changes a row's appearance when the pointer moves over it. 

tbody tr:hover {
     background-color: #dcebe3;
}

5. Table Accessibility

Accessible tables help users understand the relationship between headings and data. Use th for heading cells and td for ordinary data cells. The scope attribute identifies whether a heading applies to a row or a column. 

<table>
     <tr>
          <th scope="col">Name</th>
          <th scope="col">Marks</th>
     </tr>

     <tr>
          <th scope="row">Ahmad</th>
          <td>85</td>
     </tr>
</table>
  • scope="col": Connects a heading to its column.
  • scope="row": Connects a heading to its row.
  • caption: Gives users context about the table's purpose.

6. Responsive Tables

Tables with many columns may become wider than a mobile screen. Instead of forcing the entire page to become wider, place the table inside a container that allows horizontal scrolling. 

.table-container {
     width: 100%;
     overflow-x: auto;
}

table {
     width: 100%;
     border-collapse: collapse;
     min-width: 500px;
}

Add the table inside a div with the table-container class. On narrow screens, users can scroll sideways to view the remaining columns. 

<div class="table-container">
     <table>
          <tr>
               <th>Name</th>
               <th>Subject</th>
               <th>Marks</th>
          </tr>
          <tr>
               <td>Ahmad</td>
               <td>HTML</td>
               <td>85</td>
          </tr>
     </table>
</div>

Important Rule

Use HTML tables for displaying structured data, not for designing the overall layout of a webpage. Use CSS Flexbox or Grid for page layouts instead.
