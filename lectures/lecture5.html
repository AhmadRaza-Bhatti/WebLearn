CSS Fundamentals

Learn how to write CSS, select HTML elements, control styles, and create attractive web pages.

Lecture 05

1. Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML elements. HTML provides the structure of a web page, while CSS makes that page attractive by adding colours, spacing, fonts, borders, and layouts.

For example, HTML creates a heading, but CSS can change its colour, size, alignment, and background.

HTML

Creates the structure and content of a web page.

CSS

Controls colours, fonts, spacing, and page layout.

Design

Makes websites clear, attractive, and user-friendly.

2. CSS Syntax

A CSS rule contains a selector and a declaration block. The selector identifies which HTML element should be styled. Each declaration contains a property and a value.

h1 {
     color: green;
     font-size: 30px;
}
  • h1: The selector that targets heading elements.
  • color: The property that controls text colour.
  • green: The value assigned to the colour property.
  • font-size: The property that controls text size.

3. Three Ways to Add CSS

Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute. It affects that particular element.

<h1 style="color: green;">Welcome</h1>

Internal CSS

Internal CSS is written inside a style element in the head section of an HTML document. It is useful when styling a single page.

<head>
     <style>
          p {
               color: blue;
               font-size: 18px;
          }
     </style>
</head>

External CSS

External CSS is written in a separate .css file and connected to HTML using the link element. It is usually the best choice for a website with multiple pages because the same stylesheet can be reused. 

<link rel="stylesheet" href="style.css">

For example, the CSS rules are saved in style.css:

body {
     background-color: #f6faf8;
     font-family: Arial, sans-serif;
}

4. CSS Selectors

Selectors are used to choose the HTML elements that we want to style.

Element Selector

Selects all elements of a particular type.

p {
     color: gray;
}

Class Selector

A class can be applied to multiple HTML elements. In CSS, a class selector starts with a dot.

.card {
     background-color: white;
     padding: 20px;
}
<div class="card">First Card</div>
<div class="card">Second Card</div>

ID Selector

An ID identifies a particular element in a page. An ID selector starts with the # symbol.

#main-title {
     color: darkgreen;
}

Attribute Selector

An attribute selector targets elements based on their attributes or attribute values.

input[type="text"] {
     border: 1px solid green;
}

Grouping Selector

A grouping selector applies the same styles to multiple selectors.

h1, h2, p {
     font-family: Arial, sans-serif;
}

Descendant Selector

A descendant selector targets elements located inside another element, even when they are nested more deeply.

.card p {
     color: gray;
}

This rule selects paragraph elements inside an element with the class card.

5. Pseudo-classes and Pseudo-elements

Pseudo-classes

A pseudo-class styles an element when it is in a particular state or position. It uses a single colon. 

a:hover {
     color: green;
}

li:first-child {
     font-weight: bold;
}

The hover rule changes a link's colour when the pointer is over it. The first-child rule selects an element when it is the first child of its parent.

Pseudo-elements

A pseudo-element styles a specific part of an element or inserts generated content. It commonly uses two colons.

p::first-line {
     font-weight: bold;
}

h2::before {
     content: "★ ";
     color: green;
}

The first-line example styles the first line of a paragraph. The before example inserts a star before each h2 heading.

6. Cascade, Specificity, and Inheritance

Cascade

The cascade determines which CSS declaration is applied when multiple rules target the same element. The browser considers factors such as importance, specificity, and source order.

p {
     color: blue;
}

p {
     color: green;
}

When these rules have equal priority and specificity, the later rule wins, so the paragraph becomes green.

Specificity

Specificity is the priority given to a selector when competing declarations target the same property. Generally, an ID selector has higher specificity than a class selector, and a class selector has higher specificity than an element selector.

p {
     color: blue;
}

.note {
     color: orange;
}

#message {
     color: green;
}
<p id="message" class="note">Hello CSS</p>

In this example, the ID selector has the highest specificity among these three rules, so the text becomes green.

Inheritance

Inheritance allows certain CSS properties, such as color and font-family, to pass from a parent element to its children. Properties such as margin and border generally do not inherit automatically.

body {
     color: #334155;
     font-family: Arial, sans-serif;
}

Text inside many child elements inherits the body's text colour and font unless another rule overrides them.

7. Colour, Font, Text, and Background Properties

Colour Properties

The color property changes text colour. Colours can be written using names, hexadecimal values, RGB, or other supported colour formats.

h1 {
     color: #1f4d3b;
}

p {
     color: rgb(80, 90, 100);
}

Font Properties

Font properties control the appearance and size of text.

p {
     font-family: Arial, sans-serif;
     font-size: 16px;
     font-weight: 500;
     font-style: italic;
}

Text Properties

Text properties control alignment, decoration, spacing, and line height.

h1 {
     text-align: center;
     text-decoration: underline;
}

p {
     line-height: 1.8;
     letter-spacing: 1px;
}

Background Properties

Background properties add colours or images behind elements.

.box {
     background-color: #e8f5ee;
     background-image: url("background.jpg");
     background-repeat: no-repeat;
     background-size: cover;
}

Use a background image only when it supports the content and maintains readable text.

8. Complete CSS Example

The following example combines selectors, colours, fonts, backgrounds, and hover effects.

<!DOCTYPE html>
<html lang="en">
<head>
     <meta charset="UTF-8">
     <title>CSS Example</title>
     <style>
          body {
               font-family: Arial, sans-serif;
               background-color: #f6faf8;
          }

          .card {
               background-color: white;
               color: #1f4d3b;
               padding: 20px;
               border-radius: 10px;
          }

          .card:hover {
               background-color: #e8f5ee;
          }

          #title {
               text-align: center;
          }
     </style>
</head>
<body>
     <h1 id="title">Learning CSS</h1>

     <div class="card">
          <p>CSS makes web pages attractive.</p>
     </div>
</body>
</html>

Key Point

HTML provides structure, while CSS controls presentation. Learn selectors, CSS syntax, the cascade, and common styling properties before moving to advanced layouts.
