LECTURE 02

HTML Fundamentals

Learn how HTML creates the structure of web pages using elements, tags, attributes and content.

About This Lecture

HTML stands for HyperText Markup Language. It is the standard markup language used to define the structure and content of web pages. Browsers read HTML and display headings, paragraphs, images, links, lists and other elements to users.

HTML is not a programming language. It describes the meaning and structure of content, while CSS controls its appearance and JavaScript can add interactivity.

1. Role of Markup

Markup uses special tags to identify different types of content. For example, the h1 element represents a main heading, while the p element represents a paragraph. 

<h1>Welcome to WebLearn</h1>
<p>This is my first HTML page.</p>

The browser interprets these elements and displays the heading and paragraph in the appropriate way.

2. HTML Document Structure

Every basic HTML page follows a document structure. The DOCTYPE declaration identifies the document as HTML5. The html element contains the whole document, head stores information about the page, and body contains the content shown on the screen. 

<!DOCTYPE html>
<html lang="en">
<head>
     <meta charset="UTF-8">
     <title>My Website</title>
</head>
<body>
     <h1>Hello World</h1>
     <p>Welcome to my website.</p>
</body>
</html>
  • DOCTYPE: Declares an HTML5 document.
  • html: The root element of the page.
  • head: Contains metadata, the title and resource links.
  • body: Contains the visible webpage content.

3. Elements, Tags and Attributes

An HTML tag is written inside angle brackets. Many elements have an opening tag, content and a closing tag. Attributes provide additional information about an element and are written in the opening tag. 

<p class="intro">
     Welcome to HTML.
</p>

<a href="https://example.com">
     Visit Website
</a>
  • Tag: For example, p or /p.
  • Element: The complete paragraph structure.
  • Attribute: class and href provide additional information.

4. Nesting HTML Elements

Nesting means placing one HTML element inside another. Elements should be closed in the correct order so the browser can interpret the document properly. 

<p>
     Learn <strong>HTML</strong> fundamentals.
</p>

Here, the strong element is nested inside the paragraph and makes the word HTML important.

5. Document Validation

Validation helps identify mistakes in HTML markup. Common mistakes include missing closing tags, incorrect nesting, missing quotation marks and invalid attributes. The W3C Markup Validation Service can help check an HTML document for errors.

6. Headings and Paragraphs

HTML provides six heading levels, from h1 to h6. The h1 element is generally used for the main heading, while smaller headings organize subsections. The p element is used for paragraphs of text. 

<h1>Web Development</h1>
<h2>HTML Basics</h2>
<h3>HTML Elements</h3>
<p>HTML is used to structure web content.</p>

7. Text Formatting

HTML provides elements for emphasizing text and showing special meaning. For example, strong indicates importance, em adds emphasis, and mark highlights text. 

<strong>Important text</strong>
<em>Emphasized text</em>
<mark>Highlighted text</mark>
<del>Deleted text</del>

8. Hyperlinks: Absolute and Relative

Hyperlinks allow users to move between pages and websites. The a element uses the href attribute to specify the destination. 

<!-- Absolute link -->
<a href="https://www.example.com">
     Visit Example
</a>

<!-- Relative link -->
<a href="about.html">
     About Us
</a>
  • Absolute URL: Contains the complete address of a resource.
  • Relative URL: Refers to a resource using a path relative to the current page.

9. Images in HTML

The img element displays an image. The src attribute specifies the image location, while alt provides alternative text if the image cannot be displayed and helps users of assistive technology. 

<img src="images/photo.jpg"
     alt="A beautiful landscape"
     width="300">

10. Audio and Video

HTML provides audio and video elements for playing media in supported browsers. The controls attribute displays playback controls to the user. 

<audio controls>
     <source src="audio.mp3" type="audio/mpeg">
</audio>

<video controls width="400">
     <source src="video.mp4" type="video/mp4">
</video>

11. Ordered and Unordered Lists

Lists organize related information. An unordered list uses bullets, while an ordered list uses numbers. Each item is written inside an li element. 

<ul>
     <li>HTML</li>
     <li>CSS</li>
</ul>

<ol>
     <li>Open the editor</li>
     <li>Write HTML</li>
</ol>

12. HTML5 Features and Browser Support

HTML5 introduced semantic elements that describe the purpose of different page sections. These elements make documents easier to understand and maintain.

  • header: Introductory content for a page or section.
  • nav: A section containing navigation links.
  • main: The main content of the page.
  • section: A group of related content.
  • article: Independent, self-contained content.
  • footer: Footer information for a page or section.

Modern browsers support the main HTML5 elements. However, some newer features may behave differently across browsers, so compatibility should be checked when building a website.

Key Point

HTML defines the structure of web pages. Use proper document structure, meaningful elements, valid nesting, useful attributes and descriptive alternative text for images.
