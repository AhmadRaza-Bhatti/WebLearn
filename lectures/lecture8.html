1. Introduction to Modern CSS

CSS has developed many features that allow developers to create modern, responsive, and attractive websites without using images for every visual effect. These features include rounded corners, gradients, shadows, transformations, transitions, animations, custom properties, and media queries.

They help improve the appearance and usability of a website while keeping its structure in HTML.

Visual Effects

Create gradients, rounded corners, shadows, and transparency.

Motion

Use transforms, transitions, and keyframe animations.

Responsive Design

Adapt layouts to different screens and device sizes.

2. Rounded Corners

The border-radius property creates rounded corners on an element. It can be applied to cards, buttons, images, and other components.

.card {
     background-color: white;
     border: 1px solid #dcebe3;
     border-radius: 12px;
     padding: 20px;
}

You can also create a circular element by using a 50% border radius when its width and height are equal.

.profile-image {
     width: 100px;
     height: 100px;
     border-radius: 50%;
     object-fit: cover;
}

3. Gradients

A gradient smoothly blends two or more colours. Gradients can be used as backgrounds for headings, buttons, cards, and large sections.

Linear Gradient

A linear gradient blends colours along a straight line.

.banner {
     background: linear-gradient(
          135deg,
          #1f4d3b,
          #2e7d5b
     );
     color: white;
     padding: 30px;
}

Radial Gradient

A radial gradient spreads colours outward from a central point.

.box {
     background: radial-gradient(
          circle,
          #e8f5ee,
          #2e7d5b
     );
}

4. Shadows and Opacity

Box Shadow

The box-shadow property adds a shadow around an element, making cards and other components appear raised.

.card {
     box-shadow: 0 5px 15px rgba(31, 77, 59, 0.12);
}

Text Shadow

The text-shadow property adds a shadow to text.

h1 {
     text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.2);
}

Opacity

The opacity property controls the transparency of an element and its contents. A value of 1 means fully opaque, while 0 means fully transparent.

.image {
     opacity: 0.7;
}

Remember that opacity affects the entire element, including its children. If you only want a transparent background, use a colour format with an alpha channel instead.

5. CSS Transforms

The transform property changes an element's visual position, size, rotation, or shape without changing the normal flow of surrounding elements.

2D Transforms

Two-dimensional transforms work along the horizontal and vertical axes.

.card:hover {
     transform: translateY(-5px);
}

.image {
     transform: scale(1.05);
}

.icon {
     transform: rotate(15deg);
}
  • translate(): Moves an element.
  • scale(): Increases or decreases its visual size.
  • rotate(): Rotates the element.
  • skew(): Slants the element.

3D Transforms

Three-dimensional transforms add depth and allow rotation along the X, Y, and Z axes.

.card {
     transform: perspective(600px) rotateY(15deg);
}

Use 3D effects carefully so that content remains readable and comfortable to view.

6. CSS Transitions

A transition gradually changes a CSS property when its value changes. Transitions are commonly used for hover effects on buttons, cards, and links.

.button {
     background-color: #2e7d5b;
     color: white;
     padding: 12px 20px;
     border-radius: 8px;
     transition: background-color 0.3s ease,
                 transform 0.3s ease;
}

.button:hover {
     background-color: #1f4d3b;
     transform: translateY(-3px);
}

The transition property can specify the property being animated, the duration, the timing function, and an optional delay. Avoid applying transitions to every property unnecessarily.

7. CSS Keyframe Animations

Animations allow an element to change styles through a sequence of keyframes. Unlike a simple hover transition, an animation can run automatically and include multiple stages.

@keyframes moveUp {
     from {
          transform: translateY(10px);
          opacity: 0;
     }

     to {
          transform: translateY(0);
          opacity: 1;
     }
}

.card {
     animation: moveUp 0.6s ease;
}

The @keyframes rule defines the animation stages. The animation property sets the animation name, duration, and timing function.

You can define intermediate stages using percentages:

@keyframes changeColor {
     0% {
          background-color: #e8f5ee;
     }

     50% {
          background-color: #b7dfc8;
     }

     100% {
          background-color: #2e7d5b;
     }
}

Keep motion subtle. Users who prefer reduced motion should be considered when adding non-essential animation.

8. Web Fonts and Icon Fonts

Web Fonts

Web fonts let a website use a specific font instead of relying only on fonts installed on the user's device. They can be loaded from a font service or hosted with the website.

<link href="https://fonts.googleapis.com/css2?family=Poppins&display=swap"
      rel="stylesheet">
body {
     font-family: "Poppins", Arial, sans-serif;
}

Icon Fonts

Icon fonts provide icons through font glyphs or an icon library. In this website, Font Awesome supplies icons for navigation, lecture cards, and headings.

<i class="fa-solid fa-book"></i>
<i class="fa-solid fa-circle-play"></i>

Use meaningful alternative text or accessible labels when an icon communicates important information. Decorative icons should not create unnecessary screen-reader noise.

9. CSS Custom Properties (Variables)

CSS custom properties store reusable values such as colours, spacing, and border radius. They are often defined in the root selector so they can be used throughout a stylesheet.

:root {
     --main-green: #2e7d5b;
     --dark-green: #1f4d3b;
     --light-green: #e8f5ee;
     --card-radius: 12px;
}

.button {
     background-color: var(--main-green);
     border-radius: var(--card-radius);
}

.heading {
     color: var(--dark-green);
}

If you want to change the main green colour across a website, you can update the variable once instead of editing many separate rules.

10. Responsive Design and Media Queries

Responsive design allows a website to adapt to different screen sizes. Media queries apply CSS rules only when specified conditions are met, such as a maximum viewport width.

.container {
     width: 80%;
     margin: auto;
}

@media (max-width: 700px) {
     .container {
          width: 95%;
     }

     h1 {
          font-size: 24px;
     }
}

In this example, the container becomes wider relative to the screen and the heading becomes smaller on narrow screens.

Feature Queries

Feature queries check whether a browser supports a particular CSS feature. The @supports rule can provide a fallback for unsupported features.

.card {
     background-color: white;
}

@supports (backdrop-filter: blur(10px)) {
     .glass-card {
          backdrop-filter: blur(10px);
     }
}

11. Vendor Prefixes and Cross-Browser Compatibility

Different browsers may support new CSS features at different times. Vendor prefixes were historically used for experimental or browser-specific implementations.

.example {
     -webkit-transform: rotate(5deg);
     transform: rotate(5deg);
}

The unprefixed standard property should normally be included. Do not add prefixes to every property automatically. Check current browser support and use an appropriate build tool or compatibility reference when a feature needs special handling.

Cross-browser compatibility means ensuring a website works consistently across supported browsers and devices. Test responsive layouts, fonts, images, and important interactions in more than one browser when possible.

12. Complete CSS3 Example

This example combines custom properties, gradients, shadows, transitions, transforms, and responsive design.

<!DOCTYPE html>
<html lang="en">
<head>
     <meta charset="UTF-8">
     <meta name="viewport" content="width=device-width, initial-scale=1.0">
     <title>Modern CSS Example</title>
     <style>
          :root {
               --green: #2e7d5b;
               --dark-green: #1f4d3b;
               --light-green: #e8f5ee;
          }

          body {
               font-family: Arial, sans-serif;
               background-color: #f6faf8;
               padding: 30px;
          }

          .card {
               max-width: 400px;
               margin: auto;
               padding: 25px;
               color: var(--dark-green);
               background: linear-gradient(
                    135deg,
                    white,
                    var(--light-green)
               );
               border-radius: 15px;
               box-shadow: 0 5px 15px rgba(31, 77, 59, 0.12);
               transition: transform 0.3s ease;
          }

          .card:hover {
               transform: translateY(-5px);
          }

          .button {
               display: inline-block;
               padding: 10px 18px;
               color: white;
               background-color: var(--green);
               border-radius: 8px;
               text-decoration: none;
          }

          @media (max-width: 600px) {
               body {
                    padding: 15px;
               }

               .card {
                    padding: 18px;
               }
          }
     </style>
</head>
<body>
     <div class="card">
          <h1>Modern CSS</h1>
          <p>Build attractive and responsive web pages.</p>
          <a href="#" class="button">Learn More</a>
     </div>
</body>
</html>

Key Point

Modern CSS offers visual effects, motion, reusable custom properties, and responsive layouts. Use these features thoughtfully, test browser compatibility, and keep accessibility and reduced-motion preferences in mind.
