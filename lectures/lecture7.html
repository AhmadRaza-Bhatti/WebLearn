CSS Positioning and Stacking

Learn how elements flow, move, overlap, and use floats in web page layouts.

Lecture Video

Lecture 07

1. Introduction to CSS Positioning

CSS positioning controls where elements appear on a web page. It can be used to place badges on cards, keep navigation bars visible, create overlays, and position elements relative to their containers.

Before learning positioning, it is important to understand normal document flow. In normal flow, block elements usually appear one after another vertically, while inline elements appear within lines of text.

Normal Flow

Elements follow the normal order of the HTML document.

Positioning

Controls where an element is placed on the page.

Stacking

Controls which elements appear in front of others.

2. Normal Document Flow

Normal flow is the browser's default layout behaviour. Elements take part in the page layout according to their type and the rules of their parent container.

<div>First Box</div>
<div>Second Box</div>
<p>A paragraph below the boxes.</p>

By default, each div is a block element, so the boxes appear on separate lines. Their order follows the order in the HTML.

3. The Five Position Values

Static Positioning

Static is the default value of the position property. The element remains in normal flow, and top, right, bottom, and left do not reposition it.

.box {
     position: static;
}

Relative Positioning

Relative positioning moves an element from its original position. The element's original space is still reserved, so other elements do not move into that space.

.box {
     position: relative;
     top: 15px;
     left: 20px;
}

The box moves 15 pixels down and 20 pixels to the right from its original position.

Absolute Positioning

An absolutely positioned element is removed from normal flow. It is positioned relative to its containing block, often the padding box of the nearest ancestor whose position is not static.

.card {
     position: relative;
}

.badge {
     position: absolute;
     top: 10px;
     right: 10px;
}

Here, the card creates a positioning reference for the badge. This pattern is useful for labels such as New, Featured, or Sale.

Fixed Positioning

A fixed element is normally positioned relative to the viewport and remains in the same place when the page scrolls. Certain ancestor properties can change its containing block.

.help-button {
     position: fixed;
     right: 20px;
     bottom: 20px;
}

This is useful for floating help buttons or back-to-top controls.

Sticky Positioning

A sticky element stays in normal flow until it reaches a specified offset during scrolling. It then sticks within the boundaries of its scrolling container.

.lecture-heading {
     position: sticky;
     top: 0;
}

Sticky positioning usually needs an offset such as top: 0. It can also be affected by the scrolling container and the space available for the element.

4. Offsets: Top, Right, Bottom, and Left

Offset properties control an element's position when the selected positioning method supports them. 

.box {
     position: absolute;
     top: 20px;
     right: 30px;
}
  • top: Sets the distance from the top reference edge.
  • right: Sets the distance from the right reference edge.
  • bottom: Sets the distance from the bottom reference edge.
  • left: Sets the distance from the left reference edge.

For example, top: 20px places an absolutely positioned element 20 pixels below its containing block's top edge when that edge is the relevant reference.

5. Understanding the Containing Block

A containing block is the reference area used to calculate an element's position and dimensions. For many absolutely positioned elements, the nearest positioned ancestor is the containing block.

<div class="parent">
     <div class="child">Child Box</div>
</div>
.parent {
     position: relative;
     width: 300px;
     height: 200px;
     border: 2px solid green;
}

.child {
     position: absolute;
     top: 10px;
     right: 10px;
}

The child is positioned near the top-right corner of the parent. Without the positioned parent, the child may use a different containing block.

6. Stacking Order and Z-index

When elements overlap, the browser determines which one appears in front. The z-index property can control stacking order within the applicable stacking context.

.box-one {
     position: absolute;
     top: 20px;
     left: 20px;
     z-index: 1;
}

.box-two {
     position: absolute;
     top: 40px;
     left: 50px;
     z-index: 2;
}

When both elements participate in the same stacking context, box-two will generally appear in front because its z-index is higher.

Stacking Context

A stacking context is a group of elements stacked independently from other groups. Properties such as a positioned element with an appropriate z-index, opacity below 1, and transforms can create stacking contexts.

A child with a very high z-index cannot always appear above every element on the page. If its parent stacking context is behind another stacking context, the child remains within that group's stacking order.

7. Floats

The float property moves an element toward the left or right side of its containing block. Text and inline content can flow around it. Floats were historically used for page layouts, but modern layouts are usually easier with Flexbox or Grid.

.photo {
     float: left;
     width: 150px;
     margin-right: 15px;
}
<img src="photo.jpg" alt="A sample photo" class="photo">
<p>This text flows beside the floated image and continues below it.</p>

Clear Property

The clear property prevents an element from sitting beside floats on the specified side.

.next-section {
     clear: both;
}
  • clear: left; Clears left floats.
  • clear: right; Clears right floats.
  • clear: both; Clears both left and right floats.

8. The Collapsed Parent Height Problem

When a container contains only floated children, the container may not automatically expand to contain their height. This can cause the next section to appear in an unexpected position.

.container {
     display: flow-root;
}

Using display: flow-root creates a new block formatting context and is a simple modern way to contain floats. Another traditional solution is a clearfix technique.

.clearfix::after {
     content: "";
     display: block;
     clear: both;
}

9. Complete Positioning Example

<!DOCTYPE html>
<html lang="en">
<head>
     <meta charset="UTF-8">
     <title>Positioning Example</title>
     <style>
          body {
               font-family: Arial, sans-serif;
               background: #f6faf8;
          }

          .card {
               position: relative;
               width: 300px;
               margin: 50px auto;
               padding: 30px;
               background: white;
               border: 1px solid #dcebe3;
               border-radius: 12px;
          }

          .badge {
               position: absolute;
               top: -12px;
               right: 15px;
               padding: 6px 12px;
               color: white;
               background: #2e7d5b;
               border-radius: 6px;
          }

          .help {
               position: fixed;
               right: 15px;
               bottom: 15px;
               padding: 12px;
               background: #1f4d3b;
               color: white;
          }
     </style>
</head>
<body>
     <div class="card">
          <span class="badge">New</span>
          <h2>CSS Positioning</h2>
          <p>This card demonstrates relative and absolute positioning.</p>
     </div>

     <div class="help">Help</div>
</body>
</html>

Key Point

Relative positioning keeps an element's original space, absolute positioning removes it from normal flow, fixed positioning usually follows the viewport, and sticky positioning sticks during scrolling. Use z-index to manage overlap within stacking contexts.
